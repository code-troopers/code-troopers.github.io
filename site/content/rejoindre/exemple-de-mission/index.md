**Nous recherchons un développeur Fullstack Angular / Kotlin. Idéalement, avec une stack équivalente à celle décrite si-dessous :**

## Stack technique

**Backend**

- Spring Boot 3, 80% Kotlin 20% Java
- Hibernate
- QueryDSL
- Service annexe en python

**Frontend**

- 2 projets Angular 18
- Ensemble de librairies communes au projet en Angular 14
- Service de Génération de rapports PDF avec nuxt (Vue2) + Browserless
- WebRTC pour la partie téléconsultation

**Database**

- PostgreSQL
- MongoDB pour la partie statistiques

**Infrastructure**

- Ansible pour l’installation
- Docker swarm pour la gestion des instances
- 2 environnements (recette+prod) avec 2 machines (Appli + BDD)

**Développement**

- Gitlab Auto hébergé + Gitlab CI
- Suivi de projet via Gitlab Issues
- Sonarqube
- Metabase

**Tests automatisés**

- Junit5/jupiter/assertj pour le backend
- Testcontainer pour l’intégration
- Gatling pour la performance
- Karma + jasmine + Vitest pour le front

**Monitoring**

- Datadog
- Sentry

## Thèmes

- Psychologie et bien-être au travail
- Auto-evaluations / bilan de santé
- Formations e-learning
- Télé-consultation
- Gestion des expatriés

- Qualité du code (Tests, analyses statiques, audits)
